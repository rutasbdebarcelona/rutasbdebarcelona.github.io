# Manual editorial autónomo — Rutas B

## Regla de seguridad

1. Edita.
2. Guarda como **borrador**.
3. Revisa ES, EN, PC y celular.
4. Publica solo cuando esté correcto.

El contenido vacío se oculta cuando corresponde. La estructura responsive, reservas y seguridad no se editan como CSS libre.

## Cambiar un logo

1. Entra en `/admin/`.
2. Abre **Centro editorial → Páginas**.
3. Abre **Marca, logos y botones principales**.
4. Sube el logo horizontal/completo o el símbolo/vertical.
5. Usa el corrector para imagen completa, fondo transparente o recorte. El original se conserva.
6. Escribe el texto alternativo.
7. Guarda borrador, revisa y publica.

## Editar o crear una ruta

1. Abre **Rutas** y selecciona la ficha.
2. Completa solo estos bloques: esencial; información práctica; precio/condiciones; ficha comercial y paradas; English; medios; historial.
3. Cada parada admite título, resumen, descripción, duración, información práctica, accesibilidad, medios y traducción.
4. La presentación admite galería oculta, imagen única, cuadrícula o carrusel; lo mismo para medios de paradas.
5. Para una versión diurna/nocturna o comercial distinta, usa **Duplicar como borrador**. La copia es independiente; no se crean variantes enterradas dentro de otra ruta.
6. En la copia revisa título, slug, horarios, imágenes y estado antes de publicar.

## Fotos y videos

- Imagen principal: solo foto.
- Galería: foto o video MP4/MOV, máximo 25 MB por archivo.
- Documento: PDF, DOCX o audio.
- Todo medio nuevo entra como borrador o se publica explícitamente.
- Borradores no se muestran en la web pública.

## Mapa y sitemap

- **Centro editorial → Mapa editable** explica dónde se controla cada pieza visible.
- `/sitemap.xml` enumera las páginas públicas para buscadores.
- Si aparece algo visible que no tiene control indicado en el mapa, considéralo un punto ciego: no publiques hasta registrarlo o añadir su control.
