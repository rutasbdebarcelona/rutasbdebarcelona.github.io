# Mapa editable de la web

| Área pública | Control interno | Qué es editable |
|---|---|---|
| Marca, cabecera y pie | Centro editorial → Páginas → Marca, menú y pie | Logos, nombre, navegación, botones y textos del pie |
| Portada | Centro editorial → Páginas → Portada | Textos, orden, imágenes, fondos y modos de presentación |
| Catálogo | Centro editorial → Páginas → Catálogo | Cabecera y filtros |
| Ficha de cada ruta | Rutas → Editar | ES/EN, ficha comercial, precios, horarios, paradas, fotos, video, documentos, estado y orden |
| Quién guía | Centro editorial → Páginas → Quién guía | Foto, biografía, presentación del proyecto y contacto |
| Reserva y confirmación | Centro editorial → Páginas → Reserva / Reseñas | Textos; disponibilidad y reservas se gestionan en sus módulos específicos |
| Contacto | Centro editorial → Páginas → Contacto; Mensajes → Tipos | Textos del formulario y opciones de consulta |
| Reseñas | Centro editorial → Páginas → Reseñas; módulo Reseñas | Textos y flujo editorial |
| Publicaciones | Centro editorial → Publicaciones | Artículos ES/EN, borrador, SEO, imagen y publicación |
| Información | Centro editorial → Páginas | Preguntas, privacidad y condiciones |

La lógica de seguridad, relaciones de base de datos y responsive permanece protegida: puede evolucionar mediante versiones probadas, pero no mediante campos de CSS libre que puedan romper la web.
